# Hyderabad Crop Science Pvt. Ltd. — Corporate Web Portal

> **"Science That Protects. Innovation That Grows."**

A modern, high-performance, responsive corporate web application engineered with **React.js**, **Vite**, and **Tailwind CSS** for **Hyderabad Crop Science Pvt. Ltd.** (ISO 9001:2015 Certified).

---

## 🌾 Design Philosophy & Brand Direction

Inspired by the visual clarity and international prestige of global agriscience leaders (such as *PI Industries*, *Dhanuka*, and *Insecticides India*), while maintaining a distinctive identity rooted in Indian agriculture.

### Brand Color Palette
- **Primary Forest**: `#174D32` (Header accents, key buttons, corporate branding)
- **Secondary Green**: `#2F6B49` (Subheadings, category tags)
- **Sage Green**: `#8FAF98` (Muted highlights, badges)
- **Background Ivory**: `#F5F3EC` (Primary editorial background)
- **White Surface**: `#FFFFFF` (Card and modal surfaces)
- **Charcoal**: `#24312C` (Deep footers and cinematic overlays)
- **Gold Accent**: `#C99432` (Accreditation badges, active indicators, accents)
- **Soft Gold**: `#E9D7AA` (Secondary highlights)

### Typography
- **Headings**: *Playfair Display* (Editorial luxury serif)
- **Subheadings & Nav**: *Manrope* (Crisp modern sans)
- **Body**: *Inter* / *DM Sans* (High-legibility technical text)

## 🏛️ Navigation Structure

The site strictly contains the 5 mandated navigation sections:

1. **Home (`/`)**:
   - Cinematic Golden-Hour Hero with accreditation tag and CTA buttons
   - Who We Are (Split-screen editorial layout with ISO certification badge)
   - Company Highlights & Statistics (2014 Established, ISO 9001:2015, 6+ Categories, 7+ States)
   - Solutions for Every Stage of Growth (Interactive product categories)
   - Crop Protection Editorial Grid (Paddy, Cotton, Maize, Vegetables, Horticulture, Pulses)
   - Research & Innovation (Analytical chemistry, HPLC, Translaminar testing)
   - Formulation & Manufacturing Excellence (High-shear reactors, dust-free WG units)
   - Quality Assurance & ISO 9001:2015 Validation Protocols
   - Sustainable Agriculture ("Growing Today. Protecting Tomorrow.")
   - Corporate Gallery Preview with Lightbox Modal
   - Full-width CTA Section & Deep Forest-Green Footer

2. **About Us (`/about`)**:
   - Company Overview & Profile since 2014
   - Corporate Vision & Operating Mission
   - Chronological Timeline & Milestones (2014 – 2024+)
   - Core Values (Quality, Farmer Prosperity, Agility, Innovation)
   - Verified Organizational Strengths

3. **Products (`/products`)**:
   - Full Agrochemical Catalogue with dynamic category filtering:
     - Insecticides (Fipronil 5% SC, Thiamethoxam 25% WG, Emamectin Benzoate 5% SG, etc.)
     - Fungicides (Carbendazim 50% WP, Mancozeb Blends, Propiconazole 25% EC, etc.)
     - Herbicides & Weedicides (Metribuzin 70% WP, Pretilachlor 50% EC, Paraquat 24% SL, etc.)
     - Plant Growth Regulators (Nitrobenzene 20%, GA3, Seaweed Extract, etc.)
     - Fertilizers & Soil Nutrients (Zinc Sulphate 33%, Chelated Micro-nutrients, etc.)
     - Certified Organic Inputs (Potassium Humate 98%, Azadirachtin Neem 10,000 PPM, Trichoderma viride)
   - Real-time search by crop, active ingredient, formulation, or pest
   - Detailed Technical Modal showing composition, dosage, target pests/crops, and pack sizes

4. **Gallery (`/gallery`)**:
   - Responsive category filter (All, Products, Manufacturing, Laboratory, Agriculture, Events)
   - Masonry layout with hover effects
   - Full-screen Lightbox viewer with keyboard and mouse navigation

5. **Contact Us (`/contact`)**:
   - Corporate Office details in Surat, Gujarat (452/2, Shiv Shakti Apartment, Satya Nagar, Udhna - 394210)
   - Helpline `8258808080` & Official Email `hyderabadcropscience@gmail.com`
   - Validated Inquiry Form with feedback confirmation
   - Interactive Google Maps location embed

## 🚀 Running the Project

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
The preview server runs by default at `http://localhost:4173/`.
